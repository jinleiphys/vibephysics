# AI 辅助数理建模与应用实践

Course proposal materials for **AI 辅助数理建模与应用实践**, a 2-week summer intensive for 大一升大二 physics undergraduates at the School of Physics Science and Engineering, Tongji University.

## Schedule

- Total: 40 academic hours, organized as 10 consecutive teaching days
- Daily: 4 academic hours = 180 min teaching + 20 min buffer + 10 min mid-break (9:00 to 12:30)
- Class size: 25 to 32 students. Solo instructor when ≤ 8 groups (≤ 24 students); ≥ 9 groups require 1 graduate TA (mandatory precondition for opening the course at that scale)
- One Tongji academic hour = 45 minutes

## Files

- `index.html` — single-page立项 proposal (open in any browser, no build step)
- `SYLLABUS.md` — full 10-day course outline (v3.3, 733 lines), the authoritative artifact
- `idea-pk-output/` — design-phase dual-AI PK audit trail (curriculum direction)
- `internal-review-output/` — two rounds of dual-reviewer pre-launch audit (18 issues closed)

## Course identity in one paragraph

This is a vibe coding course adapted for freshman physics students. Five reflex actions (Spec-first PRD / Architecture-before-code / Trust but Verify / Ship something real / Skill-building), five student-generated artifacts (PRD.md / AGENTS.md / source + checklist.md / accessible artifact / SKILL.md), Anthropic 6-D prompt framework as the teaching scaffold, and an anti-template pedagogical stance: students self-generate format from principles + good/bad case studies, not from fill-in templates. China-domestic AI stack parity (DeepSeek / Qwen / Trae) is supported throughout.

See `SYLLABUS.md` for the full design, including Day-by-Day syllabus, AI usage policy with disclosure-first governance, instructor prep checklist (115 to 160 hours first-round including 10 demo recordings + ranges libraries + Day 0 install clinic), and 9 risk-mitigation entries.
