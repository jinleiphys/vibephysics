# Vibe Physics

Course proposal page for **Vibe Physics: AI 辅助数理建模与应用实践**, offered by the School of Physics Science and Engineering, Tongji University.

Teaching load: 32 academic hours, counted as 16 sessions × 2 academic hours per session. One Tongji academic hour is 45 minutes, so each session is 90 minutes.

Open `index.html` directly in a browser, or serve the directory with any static web server.
